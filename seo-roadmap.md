# PMFME Gujarat SEO Roadmap

## Phase 1 — Crawl and discovery
- `robots.txt` allows normal crawling and points to the sitemap.
- `sitemap.xml` contains the production homepage and the PMFME Gujarat landing page.
- `pmfme-gujarat.html` provides a dedicated, crawlable topical landing page.

## Phase 2 — Canonical and entity signals
- Add an explicit canonical to the homepage after reviewing the deployed `www` URL behavior.
- Keep the sitemap, canonical and internal links aligned to the same preferred host.
- Validate `WebSite`, `Person` and `WebPage` structured data with Google's testing tools before expanding markup.

## Phase 3 — Content architecture
- Build genuinely useful pages for high-intent topics such as PMFME eligibility in Gujarat, PMFME subsidy guidance, food processing business ideas and project planning.
- Give each indexable page one clear search intent and descriptive title/H1.
- Add contextual internal links between related pages.

## Phase 4 — Quality and media
- Audit image `alt` text, filenames and dimensions.
- Add useful text context around videos and other media.
- Avoid keyword stuffing, doorway pages and thin duplicate pages.

## Phase 5 — Search Console validation
- Submit the sitemap.
- Inspect the homepage and new landing page.
- Check Google's selected canonical and indexing status.
- Request recrawl only after validating the deployed pages.

The goal is sustainable visibility for relevant PMFME and Gujarat food-processing searches, not artificial ranking manipulation.
