# Gujarat Local SEO Data Source Guide

## Purpose
Use authoritative Gujarat government datasets for the district → taluka → village/area directory. Do not publish a locality page solely because a name exists in an old third-party list.

## Primary sources
- Gujarat Socio-Economic Review / Directorate of Economics & Statistics: current taluka reference.
- Gujarat Panchayats / Panchayat Department: district, taluka and Gram Panchayat lists.
- Gujarat Revenue Department / Gujarat Gazette: notifications that create or modify talukas and redistribute villages.
- Gujarat official village list: district → taluka → village mapping.

## SEO publication rules
1. Treat administrative names and boundaries as time-sensitive data.
2. Preserve historical names only as aliases/redirect context where useful.
3. Index district pages when they contain unique district-level PMFME information.
4. Index taluka pages when they contain meaningful local food-processing/agricultural context.
5. Keep village/area entries in a directory until sufficient unique, useful content exists for a standalone page.
6. Never generate pages that differ only by locality name.
7. Every indexable local page should link to PMFME eligibility, subsidy, business ideas and application guidance.
8. Add the source date/version to administrative-data pages.

## Current implementation target
Build the 34-district Gujarat hierarchy from current government data, then add current taluka and village mappings. The public directory already establishes the hierarchy; this document defines the data-quality rules for the deeper rollout.
