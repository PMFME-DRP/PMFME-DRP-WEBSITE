# Gujarat Local SEO Rollout — Phase 2

## Objective
Build a trustworthy Gujarat PMFME local-search architecture using current government administrative sources rather than mass-generated keyword pages.

## Source hierarchy
1. Gujarat Revenue Department Gazette / notifications for newly created or reorganised talukas and village allocations.
2. Gujarat Directorate of Economics & Statistics for current district/taluka reference lists.
3. Gujarat Panchayat Department for district/taluka/Gram Panchayat relationships.
4. District administration websites for local directory verification.
5. Secondary sources only for discovery; never as the sole authority for current boundaries.

## Publishing rule
A locality becomes an indexable page only after its current parent district/taluka relationship is verified and the page contains useful local PMFME information. Otherwise it remains a directory/data entry.

## Phase 2 priority
Verify the remaining 2025 reorganised/new talukas, then reconcile all district → taluka → village mappings before expanding the sitemap.

## SEO safeguards
- No doorway pages.
- No duplicate district/taluka copy.
- No unsupported claims that a PMFME application is available in a particular village.
- Local opportunity content must be relevant to the area and clearly presented as guidance.
- Administrative facts must carry a government-source reference.
- Keep `main` untouched until the SEO PR is reviewed.
